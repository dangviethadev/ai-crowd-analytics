# Demo data (local only)

Images and videos are not stored in git because they are too large. Put them here:

```
data/demo/
├── images/   # e.g. seq_000002.jpg ... (Mall dataset frames, low density)
└── videos/   # e.g. Video.avi, Video3.avi + Video3.json (zones), video1.mp4 ...
```

Zone files (`.json`) created with **Tools > Config** are saved next to each image/video in this folder.
